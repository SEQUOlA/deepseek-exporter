
# DeepSeek Chat Exporter

Привет. Это расширение я сделала для себя, чтобы быстро выгружать историю чатов из DeepSeek. Оно собирает всю переписку в один аккуратный файл в формате Markdown, чтобы потом было удобно читать, хранить в заметках или загружать в другие нейросети.

## Что оно умеет
- Выгружает чат целиком через API, поэтому не нужно ждать, пока страница прокрутится вверх.
- Сохраняет только ваши вопросы и ответы нейросети. Скрытые размышления модели в файл не попадают.
- Оформляет текст так же, как в самом чате: с заголовками, списками и блоками кода.
- Автоматически подстраивает кнопки под язык браузера (русский, английский, китайский).
- В углу есть небольшая кнопка, если захочется поддержать автора.

## Другие платформы
Я сделала отдельные версии для разных устройств, чтобы было удобно пользоваться везде:
- Для Mac: репозиторий [deepseek-exporter-mac](https://github.com/SEQUOlA/deepseek-exporter-mac). Там лежит версия под Firefox на macOS.
- Для Android: репозиторий [deepseek-exporter-android](https://github.com/SEQUOlA/deepseek-exporter-android). Так как на телефонах расширения не работают, там лежит код для создания закладки (букмарклета).

## Как установить на компьютер

### Edge или Chrome
1. Скачайте папку с файлами (или ZIP-архив) и распакуйте в любое удобное место.
2. В браузере перейдите по адресу edge://extensions/ (для Edge) или chrome://extensions/ (для Chrome).
3. Включите "Режим разработчика" (переключатель обычно находится в правом нижнем или верхнем углу).
4. Нажмите "Загрузить распакованное" и выберите папку с расширением.
5. Откройте chat.deepseek.com, обновите страницу, и в правом нижнем углу появится кнопка "Экспорт".

### Firefox
1. Введите в адресную строку about:debugging.
2. Слева выберите "This Firefox".
3. Нажмите "Load Temporary Add-on..." и выберите файл manifest.json из папки с расширением.
4. Зайдите на chat.deepseek.com и обновите страницу.
Имейте в виду: в Firefox такое дополнение работает только до закрытия браузера. После перезапуска его нужно будет загрузить заново.
